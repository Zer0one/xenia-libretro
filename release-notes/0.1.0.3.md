Rolling release of the Zer0one Xenia Edge Libretro core, developed on `main`.

### Changes

- Publish the [Libretro Baseline Review](https://github.com/Zer0one/xenia-libretro/blob/main/UPSTREAM_BASELINE_REVIEW.md) and [Upstream Integration Policy](https://github.com/Zer0one/xenia-libretro/blob/main/UPSTREAM_INTEGRATION.md). WizzardSK's Libretro reference `f23c14c71` is already fully included; no incoming port commits needed importing. The review distinguishes the local audio, lifecycle, Vulkan and newer-engine API adaptations.
- Update the README and roadmap to identify the Libretro reference base separately from the standalone engine source and record validation limits.
- Apply the desktop-only release policy: Windows x86_64, Linux x86_64/ARM64 and macOS ARM64, with matching Windows symbols. Android compilation and publication are excluded until further instruction.

This is a documentation and distribution update. Emulator source, Core Options and the integrated Xenia Edge engine `d881a29` are unchanged from `v0.1.0.2`; no new emulation fix or performance improvement is claimed. The rebuilt core reports the new tagged source revision for provenance.

### Download And Install

Platform ZIPs include the core, matching `.info`, licenses, source/workflow provenance and checksums. Windows debug symbols are a separate ZIP tied to the matching DLL. Install the core and `.info` in RetroArch's configured directories. macOS requires Apple Silicon and macOS 15.0 or later.

RetroArch and MoltenVK are separate installations. This release does not bundle a Vulkan driver, games, firmware or BIOS.

### Validation And Limits

GitHub Actions builds and publishes from the immutable release tag. Publication requires all four desktop packages and matching Windows symbols, with checksum and provenance verification. Desktop build jobs check native Libretro API/version loading; macOS also checks architecture, dependencies and signature.

Earlier boot/runtime results retain their exact build attribution. This release does not establish new gameplay, performance, audible audio, physical-controller or System Link validation.
