Rolling upstream update of the Zer0one Xenia Edge Libretro core. Development and release tags follow `main`; this release advances the fourth component to `v0.1.0.2`.

### Changes

- Full merge of Xenia Edge `d881a29125978b4eea6bf44f6ed8c33f8aea8c33`, from the previously integrated `eb31a60`.
- GPU: Xenos arithmetic and rounding corrections, float16 render targets/exports, fixed-point blending, vertex fetches, Vulkan depth-bias support and converted index-buffer allocation sizing. Mesa is updated with the read-only constant-array correction.
- Memory/kernel: user-mode mapping protections and page-table flush handling, file rename/information/status behavior, timer signaling and APC corrections.
- Services: XAM user/NUI/party/XMP behavior, media playback resource cleanup and settings, console MAC reporting and raw-Ethernet System Link APIs.
- Libretro integration: use upstream's shared audio-driver destruction and reset queued RetroPad keystrokes when a title launches. Preserve frontend pacing/audio blocks, Vulkan presentation and shutdown behavior. New assertion/disc-error paths remain headless.
- Use the bundled upstream Japanese font; release LICENSE contains the embedded fonts' OFL licenses. Standalone UI, native Metal, upstream packaging and developer tools remain excluded.

### Download And Install

Remote CI targets Windows x86_64, Linux x86_64/ARM64, macOS ARM64 and Android ARM64/x86_64. Platform ZIPs contain the core, matching `.info`, manifest, licenses and checksums. Windows symbols are distributed separately and tied to the DLL hash. Android remains non-blocking until further user instruction; any omission is disclosed below. Install the core and `.info` in RetroArch's configured directories. Use Vulkan, or Direct3D 12 on Windows. macOS minimum deployment target is 15.0.

RetroArch and MoltenVK are separate installations and are not replaced or bundled by this release. No games, firmware or BIOS are included.

### Validation And Limits

Builds, packaging and publication run entirely in GitHub Actions from the immutable release tag. Manifests record the exact source/workflow revision and run. Desktop runners check native Libretro ABI/version loading; macOS also checks architecture, dependencies and strict signature. Android receives static ELF/export/dependency/16 KiB alignment checks, without device-runtime coverage. Publication requires all desktop packages and matching Windows symbols, and verifies checksums and provenance before upload.

Earlier macOS and reported Batocera boot results concern their exact prior builds and are not relabeled as tests of this updated core. No new performance benchmark, gameplay, audio-listening, physical controller/Kinect, networking or System Link result is claimed by release packaging. Those validations remain separate.
